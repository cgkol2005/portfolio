# Προσθήκη στο portfolio

Αίτημα χρήστη: $ARGUMENTS

Όλη η σελίδα είναι το `index.html`. Δες και το `CLAUDE.md` για τις γενικές συμβάσεις.

## 1. Τι προσθέτουμε

- Κατάλαβε από το αίτημα αν πρόκειται για **δεξιότητα** (γλώσσα προγραμματισμού, εργαλείο, πιστοποίηση, ξένη γλώσσα) ή για **project**.
- Αν λείπουν στοιχεία, **ρώτα πριν γράψεις οτιδήποτε**. Για project χρειάζονται:
  - όνομα,
  - τι κάνει, σε 1–2 προτάσεις,
  - 3–5 βασικά χαρακτηριστικά ή τεχνολογίες,
  - link στο GitHub, αν υπάρχει.
- Μην επινοείς λεπτομέρειες, όπως τεχνολογίες ή features, που δεν είπε ο χρήστης.

## 2. Δεξιότητα

Οι δεξιότητες βρίσκονται στο `<section id="skills">` και είναι χωρισμένες σε κατηγορίες `<h3>`. Κάθε κατηγορία έχει από κάτω ένα `<div class="tags">`.

| Κατηγορία (`<h3>`) | Τι μπαίνει |
|---|---|
| Γλώσσες προγραμματισμού / Programming languages | Python, Java, … |
| Λογισμικό & Πιστοποιήσεις / Software & Certifications | εργαλεία, συστήματα, πιστοποιήσεις |
| Ξένες γλώσσες / Languages | γλώσσα + επίπεδο |
| Επιμόρφωση / Training | σεμινάρια (ως `<p lang="el">` / `<p lang="en">`, όχι tags) |

- **Έλεγξε πρώτα ότι η δεξιότητα δεν υπάρχει ήδη.**
- Όνομα που είναι ίδιο και στις δύο γλώσσες (Docker, ECDL, SQL) μπαίνει όπως είναι:
  `<span class="tag">Docker</span>`
- Κείμενο που μεταφράζεται μπαίνει και στις δύο γλώσσες:
  `<span class="tag"><span lang="el">Γερμανικά (B2)</span><span lang="en">German (B2)</span></span>`
- Αν η δεξιότητα δεν ταιριάζει σε καμία κατηγορία, πρότεινε στον χρήστη νέα δίγλωσση `<h3>`:
  `<h3><span lang="el">…</span><span lang="en">…</span></h3>` και από κάτω `<div class="tags">`.

## 3. Project

Τα projects βρίσκονται στο `<section id="projects">`. Το νέο project μπαίνει ως `<div class="project">` **πριν** από το «Προσωπικό Portfolio», που μένει πάντα τελευταίο.

Πρότυπο είναι το project «Client–Server Chat με Sockets» στο `index.html`. Ακολούθησε την ίδια δομή:

```html
<div class="project">
  <h3><span lang="el">Ελληνικό όνομα</span><span lang="en">English name</span></h3>
  <p lang="el">
    Περιγραφή 1–3 προτάσεων.
  </p>
  <p lang="en">
    1–3 sentence description.
  </p>
  <ul>
    <li><span lang="el">Χαρακτηριστικό</span><span lang="en">Feature</span></li>
  </ul>
</div>
```

- Αν το όνομα δεν μεταφράζεται (π.χ. «MyMarket»), γράψε απλά `<h3>MyMarket</h3>`.
- Αν υπάρχει link στο GitHub, αντίγραψε **ακριβώς** το `<a class="project-link" …>` (με το SVG) από το project «Προσωπικό Portfolio» και άλλαξε μόνο το `href`.

## 4. Ύφος κειμένων

- Γράψε φυσικά ελληνικά και φυσικά αγγλικά, όχι κατά λέξη μετάφραση.
- Ακολούθησε το ύφος των υπαρχόντων κειμένων: σύντομες, απλές προτάσεις, χωρίς υπερβολές.
- Τα ονόματα τεχνολογιών μένουν στα αγγλικά και στο ελληνικό κείμενο (TCP sockets, threads).

## 5. Έλεγχος

1. Τρέξε τον έλεγχο γλωσσών. Αν δεν τυπώσει τίποτα, όλα είναι εντάξει:
   ```
   echo '{"tool_input":{"file_path":"index.html"}}' | node .claude/hooks/check-lang.js
   ```
2. Τρέξε τον έλεγχο αντίθεσης χρωμάτων. Πρέπει να γράψει «Αντίθεση OK»:
   ```
   node .claude/hooks/check-contrast.js index.html
   ```
3. Έλεγξε την εμφάνιση σε κινητό: τρέξε `bash .claude/tools/mobile-preview.sh <φάκελος scratchpad>` και διάβασε το PNG που βγάζει με το Read. Η νέα προσθήκη πρέπει να χωράει σε 375px χωρίς κομμένο κείμενο ή οριζόντιο scroll, και να διαβάζεται σε ανοιχτό και σκούρο θέμα.
4. Δείξε στον χρήστη το κομμάτι HTML που πρόσθεσες, με τα κείμενα και στις δύο γλώσσες.

## 6. Δημοσίευση

1. **Ρώτα τον χρήστη** αν θέλει να το ανεβάσεις. **Ποτέ push χωρίς ρητό «ναι».** Αν συμφωνήσει:
   - `git commit index.html -m "<σύντομο αγγλικό μήνυμα>"`. Μόνο το `index.html`, όχι άσχετα αρχεία.
   - `git push`
2. Το push στο `main` κάνει αυτόματα deploy στο Cloudflare μέσω GitHub Actions, σε περίπου 1 λεπτό. **Μην** κάνεις χειροκίνητο deploy επιπλέον.
3. Περίμενε περίπου 1 λεπτό και επιβεβαίωσε ότι η αλλαγή φαίνεται online. Αν δεν φαίνεται, στείλε στον χρήστη το https://github.com/cgkol2005/portfolio/actions:
   ```
   curl -s https://portfolio-gkolfos.pages.dev/ | grep -c "<κείμενο που πρόσθεσες>"
   ```
4. Πες στον χρήστη τι προστέθηκε και δώσε του το link https://portfolio-gkolfos.pages.dev.
