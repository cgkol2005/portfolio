Client–Server Chat με Sockets

Εφαρμογή δικτύων όπου πολλοί χρήστες (clients) συνδέονται σε έναν κεντρικό server μέσω sockets και επικοινωνούν μεταξύ τους σε πραγματικό χρόνο. Ο server διαχειρίζεται τις συνδέσεις και προωθεί τα μηνύματα στους σωστούς παραλήπτες.

  • Επικοινωνία μέσω TCP sockets με αξιόπιστη μεταφορά δεδομένων
  • Ταυτόχρονη εξυπηρέτηση πολλών χρηστών με χρήση threads
  • Αποστολή μηνυμάτων προς όλους (broadcast) ή προς συγκεκριμένο χρήστη
  • Εμφάνιση των χρηστών που είναι συνδεδεμένοι
  • Ομαλός χειρισμός αποσυνδέσεων και σφαλμάτων δικτύου
